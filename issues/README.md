## Contributor Guidelines

1. **Pick an Issue**: Choose an unassigned issue from the list above that matches your skill level.
2. **Review Scope**: Read the `Problem Statement`, `Proposed Scope`, `Out of Scope`, and `Acceptance Criteria` carefully before writing code.
3. **Follow Guidelines**: Adhere strictly to the definitions and rules in [`CONTRIBUTING.md`](../CONTRIBUTING.md).
4. **Verification**: Run `npm run lint` and `npm run build` in `frontend/`, and `npm test` in `backend/` before submitting your PR.
